def test_calc_total():

=== Page 14 ===
規格：「滿1000 元免運」。程式碼卻寫成amount > 1000。AI 很聽話地照
程式碼反推測試，於是「1000 元要付運費」這個bug 從此有了合法身分
。
AI 讀程式碼反推的測試
def shipping(amount):
return 0 if amount > 1000 else 60
# AI 產出：
def test_shipping_1000():
assert shipping(1000) == 60
# ↑ bug 被當成正確行為鎖住
def test_shipping_1001():
assert shipping(1001) == 0
從規格（意圖）出發的測試
# 規格：滿1000 免運（含1000）
def test_shipping_1000_is_free():
assert shipping(1000) == 0
# ↑ 這條會紅→ 抓到bug
def test_shipping_999():
assert shipping(999) == 60
測試的來源是規格與範例，不是RD 昨天寫的程式碼。
3. 測現狀不測意圖：把bug 鎖進測試

深色/ 淺色主題切換…………… 4 個
