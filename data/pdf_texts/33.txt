=== Page 18 ===
蔓蔓攻擊（Manman Attack）
CASE 02
18
核心概念：利用 patch tool + sorted env index + 條件繞過，逐輪提取 credential
開新對話（新 session）
跨 session 不累積記憶，重置 model state
Step 1：patch config
植入惡意 SYSTEM_PROMPT
Step 2：terminal sorted env
取得 env vars sorted index，繞過 key name 過濾
Step 3：patch 帶出
len(v) > 60 else v 條件，直接完整輸出 key 值
取得 3–5 把 credential / 輪
結果 · OUTCOME
重複約 10 輪（~50 分鐘）
→ 10 把 credential 完整外洩
→ 3 把外部驗證成功
根因：patch tool 無 credential scan + env var 明文注入 + 無 harness-level isolation
