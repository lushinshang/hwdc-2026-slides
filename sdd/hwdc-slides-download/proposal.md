## 為什麼做

HWDC 2026（Hello World Dev Conference）大會提供了多達 55 場具備簡報/教材的議程，散落在官方線上議程系統中。為方便離線閱讀、研讀學習與知識歸檔，需要：
1. 自動化下載所有公開提供的 PDF 簡報至本地端。
2. 建立一份結構清晰、支援行動端與桌機閱讀的 `index.html`，彙整 55 場議程的講者、單位、主題介紹，並同時提供本地檔案連結與原始官方/講者外部連結。

## 要改什麼

- 新增批次下載腳本 `scripts/download_slides.py`（或 shell script），從大會 API 取得 55 筆簡報資訊，篩選出 43 份實體 PDF 下載至 `slides/` 目錄，並驗證 `%PDF` 檔頭與完整性。
- 新增 `index.html` 生成腳本或直接產生靜態網頁 `index.html`，展示全部 55 筆議程資料：
  - 支援日期分頁或切換（10/14、10/15）。
  - 卡片式排版，展示主題、講者、任職單位、簡介摘要、封面圖。
  - 具備本地 PDF 下載按鈕（針對 43 份）與原始連結按鈕（針對全部 55 份，包含 12 份外部線上簡報/專文）。
- 新增中繼資料 JSON 暫存檔 `data/slides_meta.json` 供網頁與腳本重複利用。

## 影響範圍

| 檔案 | 動作 | 說明 |
|------|------|------|
| `data/slides_meta.json` | 新增 | 存放從 GraphQL API 解析的 55 場簡報完整中繼資料 |
| `slides/*.pdf` | 新增 | 存放下載的 43 份簡報 PDF 檔案 |
| `scripts/download_slides.py` | 新增 | 負責抓取與校驗下載 PDF 的執行腳本 |
| `index.html` | 新增 | 彙整簡介、提供本地下載與原網址連結的現代化索引首頁 |
